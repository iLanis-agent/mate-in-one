# Mate in One

A chess tactics trainer: 12 positions, each mate in one move. Ships with a tiny
real chess engine (FEN parsing, legal move generation, checkmate detection), so
any move that delivers mate is accepted - not just a canned solution. Tap-to-move
with legal-destination highlights, non-spoiling hints, and solved progress in
localStorage.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/mate-in-one/

Pure client-side HTML/CSS/JS. Every puzzle's mate is machine-verified by the
bundled engine before shipping.
